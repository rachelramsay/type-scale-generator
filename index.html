Rhythm

How much leading tightens as sizes grow. 0 keeps a constant ratio.

Tunes every line-height to a 4px or 8px grid — “add and delete vertical space in measured intervals” (webtypography.net §2.2.2).

Rounds each step of the modular scale to an integer pixel size before computing rhythm.

Negative letter-spacing for display sizes, positive for small text, anchored at 0 for the base size.

Breakpoints

Interpolates each step linearly from the mobile scale (at 390px) to the desktop scale (at 1280px) instead of stepping at breakpoints.
